Tools change the shape of a task

An agent is not only a model with more steps. The tools it can access determine what evidence it sees, what actions it can take, and which mistakes become possible.

This space could later document an experiment, compare alternative workflows, or record a design decision while it is still fresh.

Placeholder observation: human oversight works best when uncertainty is surfaced before an irreversible action.

Leave room for judgment

A useful research workflow does not automate every decision. It creates clear moments where a person can inspect evidence, redirect the process, or stop it entirely.
